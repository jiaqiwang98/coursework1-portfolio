# Coursework Part I Personal Webpages

Two independent English portfolios by Jiaqi WANG.

- `version-1-ai-generated/`: AI-generated version.
- `version-2-ai-guided/`: Geek-style AI-guided version.

Publish the `main` branch root through GitHub Pages (Settings > Pages > Deploy from a branch > main > / (root)). The root `.nojekyll` serves the static files without Jekyll processing.

Each version has its own index, styles, scripts and image resources. No build or dependencies are required. The technical demonstrations are browser-local illustrations, not production integrations.
